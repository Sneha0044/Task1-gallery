# CodeAlpha Frontend Internship — Three Projects

This workspace contains three separate beginner-friendly frontend projects, built with plain HTML, CSS, and JavaScript:

1. **Image gallery** — the root `index.html`, `styles.css`, and `script.js`.
2. **Personal portfolio** — `portfolio/`.
3. **Music player** — `music-player/`.

## Open each project

Open the matching `index.html` file in a modern browser. No build tools or packages are needed. The gallery and portfolio use remote photos/fonts, and the music player uses sample audio from SoundHelix, so those assets need an internet connection.

## Learn the code

Each project folder has a README with the role of each file and suggested edits. Start by changing a heading or color, refresh the browser, then follow one button's JavaScript event to see how an interaction works.
